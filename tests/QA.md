# Проверка качества TaskFlow

## Текущая версия — Superr / Refero Styles

Источник: `https://styles.refero.design/style/cfd0fec1-f25a-4b9b-9bd0-d5b66960f2f2`. Изучены готовые CSS Variables, описание компонентов и снимок Superr. Цвета, контурные кнопки, формы и композиция адаптированы под рабочий блокнот. `js/app.js`, ключ и схема LocalStorage не менялись.

- На отдельном QA-origin `http://127.0.0.1:4173/taskflow/` пройдены **18/18** тестов `browser.test.js`.
- После реальной перезагрузки восстановлены 3 задачи, выполненный статус и прогресс **33%**; удалённые задачи не появились.
- Проверены **320, 360, 390, 520, 620, 768, 861, 900, 1024, 1100, 1280, 1440, 1920 px** через iframe соответствующей ширины. После исправления положения наклейки нет горизонтального переполнения. Проверены отсутствие пересечения поля/кнопки и фильтров/поиска, вмещение заголовка и текста задачи из 300 букв без пробелов.
- При 390 px проверено редактирование и сохранение кнопкой формы.
- Получен и просмотрен полный desktop-скриншот нового интерфейса. Отдельный мобильный скриншот получить не удалось: browser.screenshot сообщил об отсутствии видимой вкладки. Мобильная геометрия проверена программно, но это не заменяет визуальную проверку на телефоне.
- Локальные Nunito и Caveat загружаются; при открытии страницы внешние шрифтовые сервисы не требуются.
- Lighthouse на заполненном интерфейсе: **Accessibility 100, Best Practices 100, SEO 100**, без проваленных аудитов. Performance не измерялся.
- Реальные телефоны, Safari и Firefox в этом прогоне не проверялись.

## Повторная проверка после редизайна Premium Minimalism

Проверено на отдельном origin `http://127.0.0.1:4173/taskflow/`, без изменения пользовательских данных на `localhost` или других адресах.

- Все **18/18** существующих функциональных тестов пройдены на новой разметке.
- После настоящей перезагрузки восстановлены 3 задачи, выполненный checkbox и прогресс 33%; удалённые задачи отсутствуют.
- Настоящими клавишами проверены добавление по Enter, сохранение редактирования по Enter и отмена по Escape.
- Проверены viewport **320, 360, 390, 480, 620, 768, 1024, 1440, 1920 px**. Нет горизонтальной прокрутки; поле не пересекается с кнопкой, фильтры — с поиском.
- Задача из 300 символов без пробелов переносится внутри строки на всех проверенных ширинах.
- При 390 px отдельно проверено сохранение редактирования; размер шрифта поля ввода — 16 px на всех ширинах.
- Lighthouse на непустом состоянии: **Accessibility 100, Best Practices 100, SEO 100**. Performance не измерялся.
- Отдельный аудит Lighthouse пустого состояния: **Accessibility 100, Best Practices 100, SEO 100**, неуспешных аудитов нет.
- Ошибок JavaScript в консоли во время функционального прогона нет.
- Ключ/схема хранения не менялись. Из JavaScript убраны только привязки к удалённым декоративным элементам; круговой прогресс заменён линейным, анимации используют светлую тему.
- Снимок экрана получить не удалось: инструмент сообщает, что окно вкладки не видно, даже после фокусировки. Визуальная оценка по скриншоту не заявляется. Проверены DOM, геометрия, вычисленные стили и автоматический аудит. Физические устройства и Safari/Firefox отдельно не проверены.

### Исправления и технические решения редизайна

1. Удалены sidebar, дублирующая навигация, сетка статистических карточек и мотивационные карточки. Основная рабочая область сохранена со всеми функциями.
2. Удалён жёстко заданный тёмный фон анимированной копии удаляемой строки: теперь он берётся из текущей темы. Цвет вспышки выполнения использует CSS-переменную.
3. Сохранены доступные имена кнопок, focus-visible, reduced-motion и мобильные кнопки подтверждения/отмены.
4. Размеры шрифтов основного текста 15–16 px; заголовок 60–88 px. Системные шрифты не требуют сети.

## Найдено и исправлено

1. На промежуточной ширине текст кнопки добавления скрывался CSS, оставляя кнопку без доступного имени. Добавлен постоянный `aria-label`.
2. Lighthouse обнаружил недостаточный контраст подписей, метаданных и выполненных задач. Цвета осветлены; повторный аудит выполнен.
3. Убрана зависимость от внешнего шрифта: весь интерфейс работает без CDN и сетевых запросов к шрифтам.
4. Нативная проверка формы заменена собственным русскоязычным сообщением, чтобы язык ошибки не зависел от языка браузера.
5. После увеличения мобильного текста финальный повторный прогон нашёл переполнение навигации при 320 px. На самой узкой ширине скрыты дублирующие иконки фильтров; текст и счётчики сохранены. Повторно проверены все ширины, в том числе задача из 300 символов без пробелов.

## Ограничения проверки

- Скриншот получить не удалось: инструмент требовал видимое окно браузера. Снимок и полноценная визуальная оценка не заявляются. Проверены DOM, вычисленные стили, геометрия и автоматический аудит.
- Мобильная проверка — viewport Chromium, не физическое устройство и не эмуляция сенсорного оборудования.
- Safari, Firefox, экранный диктор, режим высокой контрастности ОС и реальное устройство отдельно не проверены.
- Заблокированное чтение LocalStorage покрыто обработчиком `try/catch` и аудитом кода, но отдельно принудительно не тестировалось. Принудительно проверялась ошибка записи.
- Запуск двойным щелчком (`file://`) не проверялся инструментом браузера; основной проверенный вариант — статический HTTP. ES-модулей/fetch в приложении нет; политика LocalStorage для `file://` зависит от браузера.
- GitHub Pages не опубликован. Проверена работа относительных путей в локальной подпапке, а не реальное размещение на GitHub.

## Как повторить

1. Запустите приложение на отдельном тестовом адресе/порту, где нет личных задач.
2. Удалите **только** ключи `taskflow.tasks.v1` и `taskflow.tasks.recovery` в LocalStorage тестового адреса, затем обновите страницу.
3. Выполните код запуска `tests/browser.test.js` из README. Все 18 результатов должны иметь `passed: true`.
4. Обновите страницу: должны остаться три задачи, одна из них выполнена; прогресс — 33%.
5. Вручную проверьте Enter/Escape и мобильную ширину. Для ошибок хранения используйте отдельный тестовый профиль и не меняйте данные на рабочем адресе.
